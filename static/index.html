Wiedergabe und Chat

Rechenprozesse

Mehrere Prozesse rechnen mehrere Chat-Nachrichten gleichzeitig – hilfreich, wenn sich bei vollem Chat eine Warteschlange bildet. Eine einzelne Nachricht wird dadurch nicht schneller. Jeder Prozess lädt das Modell selbst: Qwen 0.6B braucht ca. 3 GB RAM pro Prozess, 1.7B ca. 7–8 GB. „Anwenden“ startet die Prozesse neu, eine gerade gesprochene Nachricht wird dabei abgebrochen.
